이런 상황에서는 어디만 조사하면 되지?

f(x) = x² − 1 ,   g(x) = x² − ax + 3 f(x)/g(x) 가 모든 실수 x 에서 연속이 되도록 하는 정수 a 의 개수는?
1 분자도 분모도 다항함수 → 각각 모든 실수에서 연속 ✓ 여기까지는 조사할 게 없다. 성질이 다 해준다
2 ❹ 가 덮어주는 범위 = g(x) ≠ 0 인 모든 x 이 점들은 따질 필요조차 없다
3 남는 곳은 g(x) = 0 인 x  … 그게 전부 후보는 딱 여기뿐
4 모든 실수에서 연속 ⇔ 그런 x 가 아예 없다 x² − ax + 3 = 0 이 실근을 갖지 않아야
답 D = a² − 12 < 0 → −2√3 < a < 2√3 → 정수 7개 a = −3, −2, −1, 0, 1, 2, 3
